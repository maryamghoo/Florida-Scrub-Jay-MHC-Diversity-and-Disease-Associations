# GWAS phenotype preparation, association testing, annotation, and visualization

This project contains four scripts: (1) prepare incidence and intensity phenotypes, (2) run SNP association tests and functional annotation, (3) extract and merge MHC-related BLAST intervals, and (4) create a two-panel Manhattan plot. The three phenotype files written to `r_output/` are read directly by the Bash script. For plotting, copy the four PLINK association files into `r_input/`; the interval-generation script separately creates `r_input/MHC_BLAST_intervals_for_GWAS.tsv`.

## Requirements

- R packages: `dplyr`, `readr` (phenotype preparation); `data.table` (BLAST interval preparation); `data.table`, `ggplot2`, `ggrepel` (Manhattan plot).
- Bash, `bcftools`, PLINK 1.9, Python 3, Perl, and `awk`/`grep`.
- ANNOVAR, the species-specific `fsj` `refGene` database, and the corresponding annotated GFF3 for functional annotation.

**`r_input/MHC_BLAST_intervals_for_GWAS.tsv` — generated by `03_Create_MHC_BLAST_Intervals.R`**

The BLAST preprocessing script reads FASTA headers matching `>accession:start-end` in the five BLAST text files. It removes exact duplicate records, merges overlapping intervals **within each chromosome/scaffold name**, joins the accession labels from `chr_map.txt`, and writes columns `CHR`, `ChrName`, `start`, `end`, and `evidence`. Its evidence labels are descriptive group labels, **not independently measured sequence identities for each interval**. The script prints the resulting interval counts. It does not perform BLAST itself.

**`r_output/Plasmodium_GWAS_MAIN_MHC.png` — generated by `04_GWAS_Manhattan_Plot.R`**

Script 04 reads **six** files from `r_input/`: the four copied PLINK association files, `chr_map.txt`, and the generated MHC interval TSV. It plots raw association p-values as `-log10(P)` and uses the existing `FDR_BH` results to mark significant SNPs; it **does not recalculate FDR after filtering sequences for display**.

PLINK also produces `.log` files and sometimes `.nosex` files in the relevant stage folders. ANNOVAR can produce other intermediate files. The annotation TSV files have headers even when no genes are identified. Functional information is included only if present in the GFF3.

## Processing and run order

Run the R scripts from the project root (`05_GWAS_Analysis/`), because they use relative paths such as `r_input/`.

1. Prepare phenotypes:

   ```bash
   Rscript 01_GWAS_Phenotype_Preparation.R
   ```

   This creates `r_output/shared_sampleIDs.txt`, `r_output/mhc_incidence.csv`, and `r_output/mhc_intensity.csv`. Leave these files in place; script 02 reads them directly.

2. Run GWAS and annotation. Ensure `r_input/snps_afterLD_DP3_unrelated.vcf.gz` and the required annotation resources exist:

   ```bash
   bash 02_GWAS_Genotype_Association_Annotation.sh
   ```

   The Bash script resolves its project directory from its own location and can also be launched from another directory. If needed, set the external program or annotation locations:

   ```bash
   PLINK=/path/to/plink \
   BCFTOOLS=/path/to/bcftools \
   ANNOVAR=/path/to/table_annovar.pl \
   ANNOVAR_DB=/path/to/annovar_database \
   GFF3=/path/to/genome_annotation.gff3 \
   bash 02_GWAS_Genotype_Association_Annotation.sh
   ```

3. Prepare the BLAST-derived intervals. Put all five BLAST text files and `chr_map.txt` into `r_input/`, then run:

   ```bash
   Rscript 03_Create_MHC_BLAST_Intervals.R
   ```

   This writes `r_input/MHC_BLAST_intervals_for_GWAS.tsv`. The filenames must match those in script 03 exactly, including `chromosome 11.txt` (with a space).

4. Copy the four completed association files to the plotting input folder:

   ```bash
   cp bash_output_incidence/incidence_gwas.assoc.logistic r_input/
   cp bash_output_incidence/incidence_gwas.assoc.logistic.adjusted r_input/
   cp bash_output_intensity/intensity_gwas.assoc.linear r_input/
   cp bash_output_intensity/intensity_gwas.assoc.linear.adjusted r_input/
   ```

5. Create the Manhattan plot:

   ```bash
   Rscript 04_GWAS_Manhattan_Plot.R
   ```

   The PNG is saved to `r_output/Plasmodium_GWAS_MAIN_MHC.png`. The script prints the Chr11 BLAST midpoint and the list of highlighted scaffolds.

## Manhattan plot design and interpretation

- **Panels:** (A) infection incidence (logistic GWAS); (B) infection intensity (linear GWAS for infected birds using `logIntensity`).
- **Included sequences:** named chromosomes (`Chr1`, `Chr1A`, etc., and `ChrZ`) plus `HiC_scaffold_56`, `HiC_scaffold_75`, `HiC_scaffold_97`, and `HiC_scaffold_182`. Other unplaced scaffolds are omitted **only from the figure**, not the original analyses or FDR adjustment.
- **Significance:** red **open circles** indicate SNPs with `FDR_BH < 0.05`; labels give chromosome/scaffold and position (Mb). The y-axis uses the **unadjusted** p-value, `-log10(P)`.
- **MHC-related markings:** light-blue shading highlights the **entire display bin** for each of the four BLAST-related scaffolds, not the exact MHC gene intervals. A **single blue dashed line on Chr11** marks the approximate midpoint of the full span covered by the Chr11 BLAST intervals in the TSV; it is not itself a verified gene coordinate and does not show the two intervals individually.
- **X-axis:** each sequence's display width is based on its maximum observed GWAS SNP coordinate, with a minimum width of 12% of the largest observed span. This expands small display bins; between-sequence positions should **not** be interpreted as true physical distances.
- **Interpretation:** BLAST sequence similarity does not by itself establish a complete functional MHC gene, and blue regions do not indicate that nearby GWAS SNPs are significantly associated or lie within an MHC gene. Gene annotations from script 02 are independent of these plot markers.

## Analysis details and limitations

- Script 01 excludes samples labeled `Admixed`, retains individuals shared with `pop140.txt`, prepares incidence for nonmissing `Incidence`, and prepares intensity only for infected (`Incidence == 1`) individuals with nonmissing `logIntensity`.
- Script 02 uses `bcftools` to subset the VCF, PLINK to convert genotypes, `--geno 0.20 --mac 5` QC, ten PCs from PCA, and **PC1 and PC2** as covariates for additive logistic (incidence) and linear (intensity) GWAS. Significance is BH-FDR < 0.05. Annotation is performed for significant **intensity** SNPs using ANNOVAR and the supplied GFF3; it does not annotate incidence associations.
- Script 03's interval parsing depends on BLAST FASTA headers starting with `>accession:start-end`; nonmatching headers are ignored. Check that it reports the intended intervals and chromosome IDs before plotting.
- The four GWAS association files in `r_input/` are copies for plotting; original PLINK outputs remain in `bash_output_incidence/` and `bash_output_intensity/`.
- PLINK may also write `.log` and `.nosex` files; ANNOVAR may create intermediate files. Functional annotations depend on GFF3 contents, and the annotation summary TSVs can contain only headers if no gene is identified.
