# MHC Disease Analysis

This R script summarizes *Plasmodium* infection prevalence and intensity across six genetic clusters and produces a two-panel figure.

## Input

Put `MHC_sample_alleles.csv` in the `r_input` folder. This file is generated by the `01_AmpliSAS_Postprocessing` workflow and must contain `Genetic_cluster`, `Incidence`, `Intensity`, and `logIntensity`.

The script keeps birds with recorded incidence (0 or 1), excludes missing incidence records, and excludes Admixed. The six clusters are ordered Merritt Island, SL, CBC, SBC, Archbold, and Ocala.

## Requirements

Install the R packages `binom`, `dplyr`, `ggplot2`, `ggpubr`, and `see`.

## Run

Set the working directory to the project folder, then run:

```bash
Rscript MHC_Disease_Analysis.R
```

## Outputs

Files are written to `r_output/`:

- `prevalence_logIntensity.jpg`: the original two-panel style, with prevalence bars and Wilson 95% confidence intervals in panel a, and half-violin distributions of log intensity among infected birds with mean and t-based 95% confidence intervals in panel b.
- `MHC_disease_summary_by_cluster.csv`: number of tested birds, number infected, prevalence and Wilson intervals, mean infection intensity, mean log intensity, and log-intensity confidence intervals for each cluster.

Prevalence uses all birds with known incidence. Intensity summaries use only infected birds (`Incidence == 1`). `logIntensity` is read from the input file, not recalculated. When fewer than two infected birds have a nonmissing log intensity, the t-based confidence interval is unavailable.
